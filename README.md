# Sales_analysis
## Project Summary
This project provides an in-depth analysis of sales data using Excel, helping stakeholders understand performance trends across regions, products, sales channels, and customer segments. 

## Data Cleaning & Preparation
- Ensured data accuracy and consistency.

- Handled missing values and duplicates.

- Unified date and currency formats for smooth analysis.

## Key Metrics Summary
- Total Sales: 673,131,965 

- Total Items Sold: 43,005,461 units

- Total Number of Products: 25 distinct product types

- Time Range Covered: 2011 – 2020 

## Regions Overview
- Highest total sales were recorded in Giza, Alex, Delta, and Cairo.

- Upper and Canal regions had comparatively lower sales.

- Total orders per region are fairly evenly distributed, with all regions hovering around 1.4 million orders.

## Total Sold Products
A line graph visualizes the yearly total sold product units from 2011 to 2020:

- The number of products sold increased from 3.8 million in 2011 to over 4.5 million in 2020.

- Notable growth peaks occurred in 2014 and post-2016, showing overall positive growth.

## Sales Channels
- Top performing channels include Retail, Key Accounts, and Wholesale.
- Door to Door was the least performing channel with ~85 million in sales.

## Customer Segments
- Majority of the sales stem from the Consumer segment (~4.95 million), slightly surpassing the Business segment.

## Orders Overview
Total number of orders from each region is uniformly distributed, with a small variance:

- Top order volume: Sainai (1,416,379)

- Lowest order volume: Upper (1,409,846)


## Tools & Techniques
- Excel for creating interactive data visualizations and dashboards.
- Power Query for data transformation.
- Pivot Tables for summarize, analyze, and visualize the data.
